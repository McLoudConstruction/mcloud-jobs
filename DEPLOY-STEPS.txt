Photos round: deploy steps

1. Copy the files in this zip over the matching files in mcloud-jobs (same folder structure), including package.json and package-lock.json (adds fflate for zip downloads).
2. In Supabase SQL Editor, run supabase-migration-175-photo-folders.sql (after 174). Safe to re-run.
3. Push with GitHub Desktop. Vercel runs npm install and deploys.
4. In Settings, check "Photo file names" (set to McLoud by the migration).

If you push before running the migration the app still works: folders come from photo names, no thumbnails yet, no Initial Inspection folder until the migration runs.

Test on your iPhone (Safari and, if you use it, the home-screen app):
- Take photos, tap DONE, reopen the camera: it should start without "access denied".
- Brand-new job: camera should preset Initial Inspection, with Today as the next option.
- Older job: camera presets Today (2026-10-27 style), photos land in that day folder.
- Change folder in the camera, pick a named folder: no day folder is created.
- Review screen: Retake (black) / Use Photo (white).
- Photos tab: tap a photo for the viewer; Select, then Actions: Share, Markup (Done moves to next), Download (one photo = .jpg, several = .zip), Move, Delete.
- Turn on airplane mode, take a photo, turn it off: it uploads on its own.
