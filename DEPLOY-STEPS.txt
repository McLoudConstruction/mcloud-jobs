Code audit cleanup plus AI route security fix (no migration needed)

1. Copy the files in this zip into the repo, keeping the folder structure.
2. From the repo root run: sh apply-deletions.sh
   (It deletes the files listed in DELETE-THESE-FILES.txt. GitHub Desktop will show them as deleted.)
3. Push with GitHub Desktop. Vercel deploys.

What changed
- Dead code removed, duplicated helpers merged (details in the project doc claude/code-audit-2026-10-25.md).

- Five AI routes now require a signed in, active staff account, have an hourly limit
  of 150 requests per person, and write to the AI usage log:
  polish-text, generate-scope, generate-schedule, suggest-materials, extract-receipt.
  The screens that use them now send the sign in token.
